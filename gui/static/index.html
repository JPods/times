Tools

Place: Click a tool below, then click the map. Esc to cancel.
Connect: Click a CP, then click a 2nd CP to connect. Ctrl+CP to disconnect.
Move: Alt+drag a CP to move the structure.
Route: Waypoint tool + click line to add a bend. Right-click to align.

Stations
Place stations along crash corridors and high-traffic arterials. Keys 1-4 set orientation to match the road. Click the map to place. Esc to cancel. Stations are where passengers board and alight — the revenue points of the network. Noelle uses crash density as the primary signal for where stations belong.
Circles
Traffic circles connect corridors. Place them where two or more guideway routes cross. Keys 5 (N/E/S/W arms) and 6 (diagonal arms). Circles are the connective tissue — aim for roughly 1:1 ratio with stations. Only the designer knows where corridors intersect — Noelle places stations, you place circles.
Guideways
Guideway: Click a blue (outbound) CP, then a red (inbound) CP to connect. Always creates a pair — one each direction.
Waypoint: Click on a guideway to add a bend point. Drag to route around obstacles. Shift-click a waypoint to remove it.
Connect
Auto-Connect uses minimum spanning tree to connect all structures by nearest CPs. Good starting point — then manually adjust. To disconnect: Shift-click a connected CP. To remove a guideway pair: Ctrl-click the line.

Noelle
After Draft + Apply: Wild Guess adds traffic circles between station pairs and auto-connects everything. Produces a complete ~1x2 mile mesh network. It's a rough starting point — refine by moving structures and adjusting connections. The wild guess gets you from "stations on a map" to "connected network" in one click.
Draft: Noelle reads crash + traffic data and proposes stations. Toggle layer on/off — does not modify your network.
Apply: Place Noelle's draft stations into the network as real structures.
Refine: Prunes stations with no data signal, adds where signal exists. Circles untouched.
Report: Printable analysis — crash rates by road type, highway boundaries, station scores.
Local Knowledge: Answer questions about bike trails, venues, barriers that Noelle can't see in the data.

? MeshMobility — User Guide
What It Is

MeshMobility designs and simulates JPods networks on a real map. Place stations and traffic circles, connect them, then run a simulation to get door-to-door travel times for every station pair. Noelle, the network design agent, uses government traffic and crash data to propose station placement and evaluate your design.

Three Ways to Start
  1. Noelle Draft — click Draft in the Noelle panel. Noelle analyses crash and traffic data and places stations on the arterial grid. You add circles where corridors intersect.
  2. Mesh Estimate — click Mesh to lay out a uniform mesh network. Then click Refine and Noelle prunes stations with no data signal and fills gaps.
  3. Manual — place stations and circles by hand using the placement tools (keys 1-6).
Noelle — Network Design Agent
Draft Noelle proposes stations from crash + traffic data. Stations only — you add circles.
Refine Prunes stations with no data signal. Adds stations where signal exists but no structure is placed. Circles never touched.
Report Printable analysis: crash rates by road type, highway boundaries, station scores.

Noelle's key insight: local arterials are 9x more dangerous per unit of traffic than interstates. Highways are boundaries, not corridors — stations belong on the walkable grid between them.

Build a Network — Step by Step
  1. Turn on All Crashes and Traffic overlays to see where the data is.
  2. Place stations along crash corridors (keys 1-4 for orientation), or let Noelle Draft.
  3. Place traffic circles where corridors intersect (keys 5-6). Circles are the connective tissue — aim for ~1:1 with stations.
  4. Connect: click a blue outbound CP, then a red inbound CP. Or click Auto-Connect.
  5. Click Run to simulate. Green circles = dead ends. Yellow circles = orphans.

Design Principles
  • Highways are boundaries, not corridors. Nobody walks to an interstate. Stations go on the arterial grid.
  • Stations only from data. Circles require local knowledge — only the designer knows where corridors cross.
  • 1×2 mile grid is the default for US grid cities (1 mile JPods per 14 miles of road).
  • Mesh over capacity. Multiple parallel paths between stations. Never a single point of failure.
  • JPods is Middle-Mile. Station-to-station. Walking and biking handle the last mile.
