# Route-Time — Keyboard Shortcuts

All shortcuts are disabled when typing in an input field (city search, settings, etc.).

---

## Placement

Press the key to select the tool, then click the map to place. Esc to cancel.

| Key | Tool | Heading |
|-----|------|---------|
| **1** | Station N–S | 0° |
| **2** | Station E–W | 90° |
| **3** | Station NW–SE | 135° |
| **4** | Station NE–SW | 45° |
| **5** | Circle | 0° (N/E/S/W arms) |
| **6** | Circle 45° | 45° (NE/SE/SW/NW arms) |

---

## Connection Points (CPs)

Connecting uses **closest open CP** logic — click any CP on structure A, then any CP on structure B. The system automatically finds and connects the nearest available pair between the two structures.

| Action | Effect |
|--------|--------|
| Click CP | Select parent structure (gold ring) |
| Click CP on 2nd structure | Connect closest open CPs between the two structures |
| Shift+click connected CP | Disconnect pair |
| Esc | Cancel selection |

---

## Moving Structures

| Action | Effect |
|--------|--------|
| Alt+drag CP | Move structure |
| Shift+drag map | Select region (rubber-band box) |
| Drag selected structure | Move all selected structures |
| Esc during drag | Cancel, restore position |

---

## Guideway Waypoints

| Action | Effect |
|--------|--------|
| Waypoint tool + click line | Add bend point |
| Drag waypoint handle | Move bend point |
| Shift+click waypoint | Remove bend point |
| Right-click line | Add alignment point |

---

## Selection and Delete

| Action | Effect |
|--------|--------|
| Shift+drag map | Select region |
| Delete / Backspace | Remove selection |
| Shift+click node | Remove node |
| Ctrl+click line | Remove guideway pair |
